## 三、E49 唯一异常：整幅偏暗 —— 判定为**交叉淡入期截图**，非渲染缺陷

现象：设备整幅比原型暗。逐点取样后是**干净的仿射关系**：

```
设备亮度 = 0.688 × 设计亮度 + 1.8      （4 个取样点残差 < 0.3）
```

取样点（取画面中心列，避开暗角）：

| 位置 | 设计 | 设备 | 比值 |
|---|---|---|---|
| 天空 y=880 中心 | 187.0 | 130.5 | 0.70 |
| 天空 y=300 中心 | 78.1 | 55.5 | 0.71 |
| 地面 y=1000 中心 | 69.8 | 49.8 | 0.71 |
| 地面 y=1200 中心 | 28.8 | 21.6 | 0.75 |

**为什么不是渲染缺陷：**

1. 等比例变暗 + 极小常数项 ⇒ 典型的「α 合成到暗底」，不是渐变/暗角参数错。
   若是暗角参数错，比值会随半径变化；实测横向比值是边缘 0.77 → 中心 0.68，**与暗角方向相反**。
2. 代码里**只有一处**会产生这种整幅均匀 α：
   `VisualizerStage.kt:375-380` 可视化画布的 `graphicsLayer { alpha = fadeAlpha }`，
   其背后是 `:327-331` 的 `palette.background.copy(alpha = 0.72f)` 暗底层。
   `fadeAlpha` 只在**切换效果后的 ≤600ms 交叉淡入**里小于 1（`:203-239`），其余恒 1.0。
3. **E47 同页同布局却是 1.00×** ⇒ 排除截图管线、色彩配置、屏幕调光等外部因素。
4. 该截图里鸟群仍是**未收拢的横向大散带**，而原型跑 9s 后已收成 3 个紧团
   ⇒ 与「刚切到 E49、群刚 reset」的时序吻合。

**结论**：这张 E49 截图是在切换效果后约 0.4s（α≈0.69）拍的。
**建议进入效果 1s 之后重拍一张**再确认；若重拍后仍是 0.69×，才需要按渲染缺陷排查。
