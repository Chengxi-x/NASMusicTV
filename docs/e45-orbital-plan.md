## 一、需求（所有者原话拆解）

1. **太空视角看地球**：低轨道视角，地球弧面占据画面下半部（参考图 2 构图），缓慢自转，且**地面向观察者视角方向流动**（迎面感）。
2. **复用既有地球贴图**（已确认可行，见 §三）。
3. **太阳自绘**，角度可以固定不变；**月亮**入画（`moon.jpg` 贴图已有）。
4. 产出：`docs/` 下方案文档 + 验证 HTML。

⛔ **硬约束（所有者 2026-10-10）**：「技术上，不能使用 WebView + three.js，已经验证无法在电视上展现」——
E41 World（WebView + three-globe）在创维真机上无法呈现，本效果**必须走纯 Canvas 2D 通道**。

## 二、可行性结论

**可行。** 三条依据：

1. **渲染通道已验证**：E43 海边 / E44 明月均为 Compose Canvas 2D + `nativeCanvas` 直绘，已在创维 API 22 真机跑通验收；本效果的全部图元（位图网格、径向渐变、弧线）都是这两个渲染器用过的原语类型。
2. **几何可以纯数学完成**：正射投影下球面 → 屏幕是初等函数（§四），无需任何 3D 库；`drawBitmapMesh`（Android 原生 API，API 1 起可用）天然支持「静态顶点 + 逐帧纹理坐标」的球面网格变形，正是本效果的形状。
3. **原型已实证**：`e45-orbital-preview.html` 用与 Kotlin 侧等价的数学与图元预算渲染出目标画面（capture13），5 条自检全绿且 T3 带负自检。

## 四、投影与几何数学

屏幕坐标以球心为原点、y 向下。相机倾角 φ0 = 观察者纬度（子观察者纬度），**约束 φ0 ≤ 20°**（滑杆上限 200 = 20.0°）。自转轴在屏幕平面内再滚转 **ψ（轴倾斜，默认 23°，滑杆 0–60°，D9）**：极点不再位于画面正上方。

- **基向量**（本初子午线 λ0=0）：`e3=(cosφ0,0,sinφ0)` 朝相机，`e1=(0,1,0)` 东，`e2=(−sinφ0,0,cosφ0)` 屏幕上。地理系 X=本初子午线∩赤道、Y=东经90°、Z=北极。
- **正变换** `screenFromGeo(lat,lon,R,φ0,ψ)`：`dot = p·e3 ≤ 0` 即背面返回 null；未滚转系 `x = (p·e1)·R, y = −(p·e2)·R`，出口统一滚转 `(x·cψ − y·sψ, x·sψ + y·cψ)`，并携带 `depth = dot` 供剔除。
- **逆变换** `geoFromScreen(dx,dy,R,φ0,ψ)`：先**反滚转**回未滚转系 `ux = dx·cψ + dy·sψ, uy = −dx·sψ + dy·cψ`，再走原数学（`cosc = √(1−ρ²)` 等）。⚠️ 正/逆的滚转必须严格互逆（符号写反即整网格错位，实测踩过）；往返误差 **2.2e-14 rad**（T1，ψ=23° 下）。
- **网格包络**：滚转后斜放的正切圆盘盖不住全屏——把屏幕四角**反滚转**进未滚转系求 `uxMax/uyBot`，据此定 `Xhalf = min(0.999R, uxMax+8)`、`yBot = min(cy+R, uyBot+12)`；顶点在未滚转系构建、出口乘滚转落屏。
- **顶边 = 恒定 80° 纬线圈**（D4）：解 `t·c0 + s0·√(k−t²) = sin80°` 小根 `t = S·c0 − s0·√(k−S²)`；`disc ≤ 0` 的靠缘列顶到弧缘 `√k`。极点彻底排除在网格外（T3 实测 maxLat=80.0°）。
- **极冠**（替代早期极扇，见 §八 P6/P7）：80/83.5/87/89.5° 四条同心纬圈（经差 5°）+ 极点，环间四边形、最内环→极点三角形；环点与极点携带 `depth`，**四角最小深度 < 0.12 的掠缘单元剔除**（该处投影自叠，逐格仿射会拉出白色辐条）；**云层不补极冠**（半透明窄缝叠积更亮，极区少云反而自然）。极点投影 `(cx + R·cosφ0·sinψ, cy − R·cosφ0·cosψ)`，uv 取底边中点、v 取贴图北缘。
- **纹理 u 接缝**：`texUV` **故意不逐点回绕**（回绕会在 180° 经线翻转三角形）；每格相对首顶点 `unwrapU(u,u0)=u+round(u0−u)`。u 允许少量溢出 [0,1]——Kotlin 侧 `drawBitmapMesh` 的 **CLAMP 语义恰好采样到接缝相邻列**（等距柱状贴图左右边缘是同一条经线），误差亚像素；原型端用 3× 横向平铺画布模拟同一连续性。T3 实测解缠绕后 Δu=0.153 < 0.25（四分之一圈），负自检（模拟逐点 wrap01）Δu=0.995 ≥ 0.85，判据有真实判别力。
- **迎面流动**：`v = (π/2 − clamp(lat+drift)) / π`，drift 为正弦波（D3：幅值 ±4°、周期 45s），叠加恒速自转 rot=1°/s。

## 五、逐帧图元预算（TV 安全线）

真机基线（记忆 `project-baseline-tv-hwui-limits`）：创维 API 22 的 SIGSEGV 触发器是「大量互不相连的小矩形 + 无全屏操作」，合并大基元安全。本效果全部为**大基元、低条数**：

| # | 图元 | Kotlin 实现 |
|---|---|---|
| 1 | 深空底色 | 1 次全屏 fillRect |
| 2 | 星野 | 1 次 drawImage（预烘焙整屏） |
| 3 | 海色底盘 | 1 次圆弧填充（垫网格缝隙；Kotlin 侧 mesh 共享顶点可省） |
| 4 | 地表网格 | **1 次 `drawBitmapMesh`**（gx×gy 单元 + 极冠环带并入同一拓扑） |
| 5 | 云层网格 | **1 次 `drawBitmapMesh`**（半透明，同拓扑不同 rot；**不补极冠**，P7） |
| 6 | 大气边缘光 | 1 次全屏径向渐变（screen 混合） |
| 7–10 | 太阳背层（画在地球**之前**，被球盘遮挡，D8） | 光晕 / 日冕 / 日核 / 射线 ≈ 4 |
| 11–13 | 太阳前层（画在月亮**之后**，镜头伪影，D8） | 弧缘暖冠 / 横向 streak / 光斑链 ≈ 3 |
| 14-15 | 月亮 | 圆盘裁剪 + 边缘光 ≈ 2 |

**合计 ≈ 14–16 个逻辑图元/帧**，与 E43/E44 同量级（两者真机已验收）。浏览器端实发 gx·gy 次三角仿射仅为模拟，Kotlin 侧折叠进 2 次 mesh。

## 六、音频映射（方案 A · 克制氛围型，所有者选定）

只吃**律动通道**（线性），⛔ 不吃 gamma 显示通道 `spectrum`（AudioFrame 铁律 ⑨-b）：

| 源 | 目标 | 幅度 | 原型实现 |
|---|---|---|---|
| `bass` | 太阳半径（光晕呼吸） | ±15% | `r0 = sunR·H·(1+0.15·bass)` |
| `energy` | 自转速度 | ±20% | `rot += rotDegS·dt·(1+0.2·(energy−0.5)·2)` |
| `treble` | 大气边缘光亮度 | 0.5→0.75 | `aGlow = 0.5+0.25·treble` |

⛔ 不做：频谱柱、节拍闪光、几何随 beat 形变。所有调制走 `AudioSmoother` 类缓动（E44 T9 先例），无声帧逐像素等于静态定稿帧。

## 八、原型缺陷账（发现 → 根因 → 修复，Kotlin 移植时必须照避）

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| P1 | 网格状亮线贯穿地表 | 四边形整体用一个仿射：球面格非平行四边形，第四角错位，相邻格共享边采样不同 | 每格沿对角线拆 **2 个三角形**、共享顶点 uv 严格一致（`drawCell`） |
| P2 | 云层出现更亮的网格缝 | 不透明层可用的 pad 外扩（1.2px 遮 AA 缝）在半透明层重叠处**双倍 alpha** | `pad` 参数化：地表 1.2、**云 0** |
| P3 | 极区「UFO 盖」：一块光滑浅蓝透镜 | 顶行与弧缘之间用平滑渐变带填充——无纹理表面在贴图地球上一眼假；软化渐变/改切纬/压暗海基**均无效** | 删渐变带，改**极扇**（顶行→北极的退化三角，真实贴图），capture13 通过；极扇后又因轴倾斜被极冠取代（P6） |
| P4 | T3 负自检恒真空转 | ① `texUV` 从不回绕，拿它对比"解缠 vs 未解缠"是自我比较；② 所选转角使 u=0/1 缝落在球盘**外** | 负样本改为对 u0/u1 显式 `wrap01` 后再比；转角取 2.5 使缝经线（lon≈37°）落在视野内 |
| P5 | 阈值 0.08 挡 80° 切纬（Δu=0.120） | 阈值为 70° 切纬时代拍脑袋值，几何变了没跟着变 | 按「四分之一圈翻转」原理重写为 **0.25** + 负自检 ≥0.85（强化判据而非放宽，遵循所有者既有裁决口径） |
| P6 | 轴倾斜后极扇拉出横跨全盘的棱面「货架」（capture14–21） | 滚转使包络变宽（Xhalf 488→981），顶行→极点的单角扇形三角随之被拉长到横跨整个极区，仿射近似彻底失效；期间两次误诊（以为是包络缺口，改坏 `yBot` 又改反滚转符号） | 极扇改**同心纬圈极冠**（80/83.5/87/89.5° 环带 + 极点，单元 ≤5° 经差），capture24 货架消除。教训：隔离截图（关云/关极冠各一张）比整帧反复调参定位得快 |
| P7 | 极冠在右弧缘处仍现白色**风车辐条**（capture24/26） | 纬圈带掠弧缘处投影**自叠**（近侧带与远侧带压进同一条窄缝），逐格仿射叠绘拉出辐条；云半透明层叠积后更亮。用「关云单地表」（capture27）判定辐条主体来自**云层极冠** | 双层分治：地表层按四角最小深度 `<0.12` 剔除掠缘单元；云层**直接不补极冠**（极区少云反而自然），capture28 通过 |

## 九、决策记录

- **D1 渲染通道 = 纯 Canvas 2D + drawBitmapMesh**（所有者硬约束：WebView+three.js 已验证电视上无法展现）。
- **D2 音频映射 = 方案 A 克制氛围型**（所有者选定）。
- **D3 迎面移动 = 正弦漂移**（±4°、周期 45s）叠加恒速自转 1°/s——避免匀速造成的"传送带"感。
- **D4 极点处理 = 网格切在 80° 纬线圈 + 同心纬圈极冠补全**（极冠含掠缘深度剔除，见 P6/P7），φ0 ≤ 20°（顶行合法 Δu 随 1/cos(lat) 增长：70°→0.055 / 75°→0.087 / 80°→0.153，均在 0.25 判据内）。
- **D5 太阳角度固定**（所有者允许），仅 bass 呼吸；不做周日运动。
- **D6 云层 = 程序化 fbm 烘焙**（`earth_glow.jpg` 实为灯光辉光，非云覆盖；hash 噪声 + 气候带偏置，T4 保证确定性）。
- **D7 命名与编号待所有者裁决**：建议枚举 `LOW_ORBIT`（⚠️ 勿用 `ORBITAL`——与既有 `ORBITAL_RINGS`「太阳系」近名）、显示名建议「近地轨道」、`ordinalLabel "45"`、Tier 建议 **ADV**（两次全屏 mesh + 半透明层，LOW 档降密度后三档均可提供，`needsParticleBudget=false` 同 E43/E44）。
- **D8 太阳藏于弧缘后、只露一线**（所有者裁决 2026-10-10："不能直接出现太阳，应该被地球挡住，露一点就行"）：日心距 `R·(1+sunLiftFrac)`，默认 `sunLiftFrac = −0.02`（日心落在球盘内 2%，仅日冕溢出弧缘）；渲染按**遮挡拆两层**——背层（光晕/日冕/日核/射线）画在海色底盘**之前**、被地球盘自然盖住，前层（弧缘暖冠/横向 streak/光斑链）画在月亮**之后**、语义即镜头伪影。Kotlin 侧照抄同一绘制次序，滑杆「太阳仰角」允许负值（−30…90）。
- **D9 自转轴倾斜 ψ=23°、极点不在正上方**（所有者裁决 2026-10-10："极点不能在上方，应该倾斜旋转"）：实现为屏幕平面内滚转——网格在**未滚转系**构建、出口统一旋转（数学见 §四），滑杆 0–60° 可调；滚转使包络必须按屏幕四角反滚转重算（P6 的诱因之一）。派生缺陷 P6/P7 均已闭环。

## 十二、原型使用说明

浏览器直接打开 `docs/e45-orbital-preview.html`：左栏滑杆实时调 φ0 / **轴倾斜 ψ（0–60°，默认 23°）** / 地平位置 / 球径 / 自转 / 漂移 / 网格密度（默认 64×32）/ 云不透明度 / 太阳方位与**仰角（−30…90，负值=藏于弧缘后，默认 −2）** / 月亮位置 / 星密度；顶部按钮跑 5 条自检（T1–T5，含 ψ=23° 下的投影往返）并暂停；`__E45_capture(w,h)` 供脚本化离屏截图。控制台可调 `window.__E45.P`。
